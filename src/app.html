Connect

Run this once in Minecraft chat

Opening a world from the Worlds tab copies it for you.

/connect localhost:8080
  1. Open a world with cheats on
  2. Press T for chat, paste with Ctrl+V, press Enter
  3. Type ai hello to start talking
Minecraft has no way to run this command from outside the game, so it has to be pasted once per session.

Playing on a phone or tablet

Same Wi-Fi, no app to install on the device.

The bridge accepts connections from your whole network, so Minecraft on a phone can use this computer. Type this in the game's chat there instead:

/connect 0.0.0.0:8080

The pack still has to be in the world you play there. Import it on the device once, and this computer has to stay on and running this app.

About

What this is

Bedrock AI lets you talk to a real AI while you play, in chat.

You type a question in Minecraft chat and the answer comes back from a live language model. It can also do things for you - give items, change the weather, teleport you, clear the trees above your head - because it can run commands in your world.

Why is this an app, and not just an add-on?

This is the question I got the most, so here is the honest answer.

Add-on scripts run inside Minecraft, and Minecraft does not let them reach the internet. The module that would allow it, @minecraft/server-net, only exists on Bedrock Dedicated Server - the software you rent for a hosted server. It is not in the game you play at home. So a pack on its own can never call an AI, no matter how it is written.

But Minecraft can reach out on its own. The game has a WebSocket client built in, and /connect tells it to connect to a server on your computer. That is what this app is: a small server running on your machine. Your chat goes to it, it asks the AI, and it sends commands back into your world.

So the two halves do different jobs. The behaviour pack this app installs reports what is happening around you - your health, inventory, biome, what you are holding - and the app carries that to the AI and brings the answer back. Neither half can do the job alone.

Why do I still have to type /connect?

Because nothing outside Minecraft can make it connect. Microsoft documents a set of links that can drive the game from outside - open the store, join a realm, import a pack, load a world - and this app uses the one that loads a world. There is no link for the WebSocket connection.

So the command has to be pasted once, each time you start playing. Opening a world from the Worlds tab copies it for you, so it is press T, then Ctrl+V, then Enter.

Does it change my worlds?

Only the world you choose, and only by adding the behaviour pack to it. Nothing else in the world is touched, and the app always asks before it writes anything. The AI can run commands while you are connected, so keep cheats on only in worlds where you are happy for that.
